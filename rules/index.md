# How agents work in the maintainer's projects

The working rules for every agent session in every repository of astrapi69 and lightblueseas: the single source of truth. The files under core/ are loaded into every session; the topic files are read when the work needs them. A project keeps in its own repository only what is specific to it. Rules that name local paths, machines, keys or infrastructure are kept in the maintainer's private notes and loaded beside these.

Loaded into every session:

@core/agents.md
@core/git-and-prs.md
@core/decisions.md
@core/security.md
@core/quality.md
@core/writing.md

Read on demand: [Git, pull requests and issues](git-and-prs.md), [Releases](releases.md), [Testing](testing.md), [The Java family](java-family.md), [Documentation](docs.md), [Code style](code-style.md), [Tooling](tooling.md), [Security](security.md), [Decisions](decisions.md), [Working as an agent](agents.md).

Where each rule comes from: [provenance.md](provenance.md). How the projects are made: [AI_USAGE.md](../AI_USAGE.md).
